# 📊 Data Analyst Copilot

Автоматизированный инструмент для анализа CSV-файлов и создания отчета качества данных.

Проект помогает Data Analyst быстро проводить первичный анализ данных (EDA):

- поиск пропусков
- поиск дубликатов
- поиск выбросов
- статистический анализ
- профиль колонок
- корреляционный анализ
- генерация HTML отчета


## 🚀 Возможности

### Анализ качества данных

- количество строк и колонок
- пропущенные значения
- полные дубликаты
- дубликаты без учета ID


### Exploratory Data Analysis (EDA)

- расчет статистических показателей
- анализ числовых колонок
- поиск аномальных значений
- корреляционный анализ
- построение графиков


### Автоматические выводы

Система формирует рекомендации:

- обнаружение пропусков
- поиск подозрительных значений
- описание проблем в данных
